## 🚀 Descripción

**BiilsGestor (neoApp)** es una solución educativa enfocada en el análisis y control de *gastos hormiga* mediante el uso de herramientas modernas de desarrollo y ciencia de datos.

Este proyecto integra:

- 🐍 **Python + Pandas** para análisis de datos
- ⚛️ **React** para el frontend
- ☕ **Spring Boot** para el backend

El objetivo es ayudar a las personas a identificar patrones de consumo pequeños pero frecuentes que impactan significativamente sus finanzas personales.

---

## 🎯 Objetivos del proyecto

- 📊 Analizar hábitos de gasto usando datos estructurados  
- 🔍 Detectar patrones de gastos hormiga  
- 💡 Generar insights financieros personalizados  
- 🧠 Fomentar el aprendizaje práctico de análisis de datos
